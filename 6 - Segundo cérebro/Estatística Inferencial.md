### Definição

A estatística inferencial abrange os métodos necessários para se obter generalizações mais elaboradas a respeito de uma população a partir dos dados coletados de uma amostra, ==representando o aspecto analítico da estatística==[^1].

### Principais aspectos

Possui como objetivo a extração de insights. 

São elaboradas Hipóteses, a partir da análise dos dados coletados e tratados na fase descritiva[^2], com a finalidade de definir possíveis senários decorrentes destes dados. Analisam-se as possibilidades de ocorrência destes senários, considerando a incerteza e a variabilidade amostral, e intervalos de confiança validam estes senários em um intervalo de possibilidade razoável para o estudo realizado.

Com a validação de hipóteses, é possível realizar previsões de eventos futuros embasadas puramente na análise de dados. Com um gral considerável de assertividade, é possível se preparar para desastres e investir em oportunidades antes mesmo destes ocorrerem.
