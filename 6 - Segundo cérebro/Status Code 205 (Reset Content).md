### Definição

O status code[^1] 205[^2] indica que o servidor processou corretamente a requisição[^3] enviada e deseja que o usuário de um refresh na página a fim de ==restaurar o estado original da mesma==.

### Relevância

É importante para notificar ao usuário de uma ação necessária para a boa completude de seu processo de requisição. ==Muito utilizado para indicar a necessidade de limpar formulários, caixas de texto e outros mecanismos de input==.
