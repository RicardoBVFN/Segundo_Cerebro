### Definição

Diferentemente do SQL[^1], os bancos de dados[^2] noSQL (not only SQL) possuem uma estruturação mais flexível dos dados, podendo seguir muito outros padrões (orientado a objetos, documentos, grafos, colunas e chave-valor). Por sua maleabilidade, campos (dados) podem variar com mais facilidade entre registros. Normalmente, cada tecnologia possui sua própria API de operações no banco, a pesar de algumas utilizarem a linguagem SQL. A maioria dos modelos pretere BASE (Basically Available, Soft state, Eventual consistency), mas alguns já oferecem suporte para ACID.

### Relevância

Por sua maior fluidez, os bancos de dados noSQL são amplamente implementados em aplicações modernas, que lidam com com dinamismo de dados em sua operação cotidiana. E-comerce, aplicações IOT e sistemas críticos são só alguns exemplos do uso de noSQL em nosso dia a dia.

Além disso, por ser um modelo naturalmente mais distribuído, é ideal para escalamento horizontal de servidores. A fim de aumentar o poder computacional, distribui-se a demanda entre mais máquinas em um servidor, sem necessariamente aprimorar individualmente estas.
