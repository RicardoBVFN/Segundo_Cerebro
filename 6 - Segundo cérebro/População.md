### Definição

Para o estudo da estatística e probabilidade[^1], uma população consiste no ==universo completo de indivíduos em um estudo==. É o alvo do estudo e é a partir de uma população que são extraídas as amostras[^2] para a análise estatística[^3].

### Exemplos

São exemplos de populações: total de habitantes de uma cidade, banco de dados completo, total de alunos em uma universidade e todos os automóveis de uma concessionaria.
