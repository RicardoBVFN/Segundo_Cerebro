### Definição

Nesta amostragem probabilística[^1] os indivíduos de uma amostra[^2] são selecionados da população[^3] por meio da aplicação de ==intervalos regulares entre os escolhidos==. Para a boa aplicação desta técnica, a população deve estar organizada em roll.

### Relevância

Por normalmente partir de uma organização em roll, esta é uma boa técnica para realizar análises de frequência de elementos em uma população. Também é indicada para grandes volumes de dados já que seu processo de seleção não demanda grande capacidade de processamento.

Tem como desvantagem o fato de que para seu bom funcionamento é exigido a ordenação dos dados. Caso o volume de dados seja muito extenso e estes não estejam ordenados, demandará um custo operacional elevado.
