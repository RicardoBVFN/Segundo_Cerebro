### Definição

O status code[^1] 200[^2] diz que ==a request[^3] foi recebida, processada corretamente e a response[^4] foi devolvida de forma aceitável==, sem intercorrências na comunicação entre cliente e servido. Tudo ocorreu bem.

### Relevância

É fundamental para confirmar se a operação requisitada pelo cliente foi realizada com sucesso e que a comunicação com o servidor foi realizada de forma correta.
