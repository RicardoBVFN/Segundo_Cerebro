### Definição

Bancos de dados[^1] SQL são bancos em que sua ==estrutura interna é orientada à tabelas (linhas e colunas)==. Sua estrutura é rígida e bem definida, alterar a estruturação original[^2] requer migrar todos os dados contidos nas tabelas. Por padrão, é utilizada a linguagem SQL (Structured Query Language) para realizar operações em seus dados (consultas, alterações e deleções). São compatíveis ao ACID (Atomicidade, Consistência, Isolamento e Durabilidade).

São exemplo de bancos de dados relacionais: Oracle database, MySQL, PostgreSQL, SQLite, SQL Server, dentre outros.

### Relevância

Por ser um modelo tradicional e logicamente mais simples, é indicado para aplicações cuja operação não exige tanta flexibilidade, como em sistemas financeiros, cartórios e bibliotecas. Sua estruturação intuitiva facilita a gestão e o controle dos dados por parte do administrador.

Além disso, são amplamente aplicados em modelos de escalação vertical de servidores, no qual será aprimorado o poder computacional por meio de modificações individuais (upgrade de peças, troca de cabos, etc).
