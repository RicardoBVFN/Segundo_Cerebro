Para melhor compreensão, o processo de análise estatística de dados pode ser dividido nas fases de:

### 1. Coleta

Obtenção de fato dos dados que serão utilizados  no estudo. Estes podem vir de diversas fontes, como APIs, logs, formulários, sensores, bases públicas, pesquisa *in loco* dentre outros.

### 2. Organização

Consiste na estruturação dos dados coletados para análise. Eliminam-se os dados irrelevantes, tratam-se os dados faltantes e ordenam-se os demais para assim realizar as análises dos mesmos.

### 3. Análise

Assim como na anterior, são empregados métodos da estatística descritiva[^2] para tratar de forma preliminar os dados, mas desta vez realizando as primeiras análises de fato. São determinados medidas de tendencia central, medidas de dispersão e padrões iniciais.

### 4. Interpretação

Aqui são aplicadas técnicas da estatística inferencial[^3] para se extrair padrões e tendências mais elaboradas dos dados. Hipóteses são elaboradas e validadas tendo como produto final insights que posteriormente serão apresentados na conclusão da pesquisa.

### 5. Apresentação

Por fim, as análises obtidas na etapa de organização são apresentados em forma de gráficos e tabelas legíveis para uma compreensão facilitada destes. Tendo como embasamento esta introdução, são comunicados os insights para o público final, encerrando a pesquisa.
