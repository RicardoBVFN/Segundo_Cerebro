### Definição

SGBD consiste no software responsável por agir como ==interface para o usuário== na gerência de um banco de dados[^1]. É por meio deste que o gerente de dados vai realizar consultas, escritas ou deleções em sua base de dados.

### Relevância

O SGBD é fundamental para o bom funcionamento de operações já que proporciona ao usuário administrador maior usabilidade no gerenciamento do banco. Sem uma interface como mediadora neste processo seria necessário muito mais esforço e energia por parte do operador, o que iria requerer tempo e energia que o mercado não possui.

Além de agilidade, o SGBD é a garantia de que todas as operações em um banco de dados vão seguir o mesmo padrão em todos os projetos e processos. Também é responsável por gerenciar o acesso ao banco de dados, realizar o tratamento de ocorrências (instâncias), separar os dados do modelo de dados e intermediar a execução do programa e os dados em si.
