### Definição

A tipagem de dados consiste na definição do modelo de dados que irá representar um valor em um software.

### Relevância

A tipagem de dados é fundamental para  tratamento e armazenamento de dados[^1] nos meio digitais.

Cada tipo de dados requer um tratamento diferenciado em seu armazenamento dentro de sistemas digitais. Uma boa tipagem é o primeiro passo para se fazer um bom uso de uma informação por para esta ser fielmente representada esta deve representada em um modelo fiel à natureza do dado.

Estando bem representado, só então essa informação pode ser manipulada por operações congruentes com sua tipagem. A coesão lógica e operacional do funcionamento do sistema são fortemente dependentes de uma tipagem bem feita de suas variáveis.
