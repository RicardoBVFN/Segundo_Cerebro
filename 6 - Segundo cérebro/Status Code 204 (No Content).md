### Definição

O status code[^1] 204[^2] indica que a requisição[^3] foi processada com sucesso mas a ==response[^4] retornou nenhum conteúdo==.

### Relevância

Este status é ideal para ==verificar se operações de deleção foram realizadas com sucesso dentro do servidor==.
