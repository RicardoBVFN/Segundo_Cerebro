### Definição

O status code[^1] 202[^2] indica que a requisição[^3] foi aceita pelo servidor para prosseguir com seu processamento.

### Relevância

É ideal para ==verificar se operações de login ou acesso a informações mais bem protegidas foram realizadas com sucesso==.
