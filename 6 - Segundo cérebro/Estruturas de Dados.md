### Definição

São estruturas de dados os modelos lógicos utilizados para estruturar, organizar e gerenciar dados[^1] de determinada aplicação/projeto. Buscam eficiência e otimização nas operações e tratamento dos dados[^2].

### Relevância

Os enormes montantes de informações, de variação e abrangência quase absolutas, de nada serviriam sem as estruturas de dados.

Os modelos de estruturação de dados representam uma parte fundamental na análise e gerenciamento dessas informações. Modelos bem estruturados podem representar ganhos exponenciais de performasse nas operações, tanto de consulta quanto de edição e inserção.

Como exemplo pode-se sitar as Árvores Binárias[^3] para armazenamento de dados, que representam eficiência na ordem de 2^n para inserção e consulta de dados em comparação com modelos lineares de estruturação. Todavia, não necessariamente para se estruturar os dados usa-se uma estruturação elaborada. Muitas vezes, uma simples tipagem e atribuição de propriedades já facilita bastante o processo de tratamento de dados. como exemplo pode-se sitar a definição de um conjunto de caracteres como Sting em um programa.
