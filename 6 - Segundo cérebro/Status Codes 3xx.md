### Definição

O status codes da casa dos 3xx representam ações de movimentação/redirecionamento do usuário para que a request[^1] possa continuar a ser processada. 

> [!NOTE] Definição IETF 
> "The 3xx (Redirection) class of status code indicates that further
   action needs to be taken by the user agent in order to fulfill the
   request."
   .
   [Link](https://datatracker.ietf.org/doc/html/rfc7231#section-6.4)

### Relevância

Esse tipo de status code é importante para direcionar o comportamento do usuário principalmente em navegaçoes pela internet. ==Estão presentes em mudanças de páginas, navegações ou qualquer outra ação que remova a presença do usuário da pagina original da requisição==.
