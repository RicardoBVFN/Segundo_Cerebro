### Definição

Uma String consiste em um tipo de dados normalmente referente a uma ==sequência de caracteres.== Dependendo da linguagem em questão, pode ser implementada como um objeto inteiro ou como um vetor[^1] de objetos do tipo Char[^2].

### Relevância

Sendo amplamente utilizados em projetos de desenvolvimento, objetos do tipo String são ideais para receber, tratar, manipular e armazenar elementos como um nome de usuário, resposta escrita a uma pergunta em um formulário, cpf, endereço, dentre outros.
