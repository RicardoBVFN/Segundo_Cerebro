### Definição

O satus code[^1] 411[^2] se refere ao erro ocorrido quando o servidor necessita da informação referente ao tamanho do conteúdo a ser buscado e ==esta não é fornecida pelo usuário em sua requisição==[^3]. O usuário deve reenviar sua requisição contendo um comprimento/tamanho específico para o conteúdo almejado.

### Relevância

O envio desse status para o cliente quando necessário é crucial para indicar com mais precisão o erro cometido e facilitar o processo de correção para o reenvio da requisição.
