### Definição

Consiste no ==conteúdo de fato devolvido pelo servidor em resposta à requisição[^1] recebida==. No modelo REST[^2], pode ser de múltilos formatos de mídia, desde JSON (mais utilizado), até um HTML puro. Se encontra logo abaixo da response message body[^3]
### Exemplos

```


<h1>My Home page</h1>
```

### Relevância

Representa a resposta enviada pelo servido, a qual será consumida pelo cliente.
