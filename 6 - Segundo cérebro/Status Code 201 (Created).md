### Definição

O status code[^1] 201[^2] indica que, em decorrência do processamento da requisição[^3], ==um novo elemento foi criado no servidor==.

### Relevância

É uma forma prática de ==verificar se operações de cadastramento foram realizadas com sucesso==. Criação de usuário e cadastramento de um novo produto são alguns exemplos desse tipo de operação.
