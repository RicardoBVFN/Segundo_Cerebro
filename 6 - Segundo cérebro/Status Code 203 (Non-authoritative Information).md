### Definição

O status code[^1] 203[^2] indica que a requisição[^3] foi processada com sucesso mas a informação sofreu alterações de um servidor proxy da resposta com status 200 na origem.

### Relevância

É útil para esclarecer o motivo de uma formatação indesejada da resposta, mesmo ela tendo sido bem sucedida, ou para indicar que não será possível obter a informação de forma bruta do servidor.
