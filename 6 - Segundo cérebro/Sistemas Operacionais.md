### Definição

Um sistema operacional consiste em um dispositivo de software responsável por ==gerir recursos operacionais, integrar os componentes de hardware e oferecer uma melhor interface para o usuário== de uma máquina. Costuma agir em conjunto com uma interface gráfica para facilitar a usabilidade do sistema.

### Relevância

Mesmo antes do surgimento dos computadores modernos, havia uma demanda por um sistema operacional.

Mesmo na época em que computadores ocupava salas enormes, não possuíam monitores e funcionavam a base de bobinas, a necessidade de focar mais na obtenção do resultado do que no processo para obtê-lo era real. Máquinas essencialmente possuem a função de resolver problemas e facilitar a vida de seus usuários. A operação de uma máquina sem uma boa interface torna-se sem propósito a partir do momento em que esta traz mais complicações ao usuário do que se este decidisse solucionar o problema por conta própria.

A disseminação dos computadores tornou essa necessidade ainda mais urgente. Se estudiosos e especialistas em desenvolvimento de software e hardware eram incapazes de fazer uso de uma máquina sem um sistema operacional, quem dirá o público leigo. Com muito mais dinheiro em jogo, rapidamente os SOs se adaptaram a essa demanda em ascensão. Interfaces gráficas, processamento em segundo plano e virtualização[^1] são apenas alguns exemplos de evoluções que ocorreram desde que esta ferramenta se popularizou no mercado em geral.

Hoje, sistemas operacionais elaborados, com múltiplas funcionalidades e de interface amigável e intuitiva nunca foram tão valiosos. Com problemas mais complexos a cada dia e com cada vez mais aparelhos demandando processamento individual (IOT) é seguro dizer que atualmente temos um sistema operacional para quase tudo.
