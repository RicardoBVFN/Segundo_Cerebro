### Definição

O modelo de dados tem como principal função ==definir formalmente a estrutura de um banco de dados==[^1]. É responsável por formalizar os tipos de dados, como estes serão alocados, suas amplitudes e como vão se relacionar uns com os outros.

### Relevância

A presença de um modelo de dados é de vital importância em um projeto pois é ele que garante a fidelidade do projeto com a demanda real. Por meio da definição de um padrão a ser seguido previamente à execução, não sobra margem para interpretação ou desvio de proposta (salvo casos de alteração pelo próprio demandante). 

O modelo de dados é uma das garantia do cliente de que seu produto será condizente com o que foi solicitado no início do projeto.
